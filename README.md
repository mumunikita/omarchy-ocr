# omarchy-latex-ocr

Локальное распознавание **текста и математических формул** с экрана в формат Markdown + LaTeX для [Omarchy](https://omarchy.org/) / Hyprland.

Приложение позволяет выделить область экрана и по горячей клавише получить готовый Markdown в буфере обмена:

```markdown
Теорема Пифагора: $a^{2}+b^{2}=c^{2}$ верна для прямоугольных
треугольников, а $E=m c^{2}$ связывает массу и энергию.
```

Обработка выполняется полностью локально на CPU (GPU). Облачные сервисы и API-ключи не используются.

## Возможности

- **Русский и английский текст** — распознавание через EasyOCR.
- **Формулы → LaTeX** — строчные `$...$` и выключные `$$...$$` (Pix2Text MFD + MFR).
- **Высокая скорость** — демон удерживает модели в памяти; распознавание занимает 1–3 секунды вместо 15–20.
- **Гибкий жизненный цикл** — работа только при открытом Obsidian, по расписанию (дни недели + часы) или постоянно.
- **Выбор горячей клавиши** при установке, включая пользовательскую комбинацию.
- **Резервный режим** — при недоступности демона запускается one-shot режим вместо ошибки.
- **Фоновая обработка** — распознавание не блокирует интерфейс.

## Требования

- Arch Linux / Omarchy, Hyprland (Wayland).
- `grim`, `slurp`, `hyprpicker`, `wl-clipboard`, `socat`, `jq`, `uv`, `python`.
- ~2.5 ГБ на диске (venv + torch CPU + модели).
- ~1.4 ГБ RAM при запущенном демоне.

Установщик автоматически устанавливает недостающие пакеты через `pacman`. На других дистрибутивах пакеты устанавливаются вручную, запуск выполняется с флагом `--skip-deps`.

## Установка

```bash
git clone https://github.com/mumunikita/omarchy-ocr.git
cd omarchy-ocr
./install.sh
```

Установщик выполняет следующие действия:

1. Проверяет и устанавливает системные зависимости.
2. Запрашивает режим работы демона (Obsidian / расписание / всегда).
3. Создаёт venv `~/.local/share/pix2text-venv` и устанавливает Pix2Text, EasyOCR и CPU-сборку torch.
4. Загружает модели (~450 МБ) в `~/.pix2text` и `~/.EasyOCR`.
5. Копирует скрипты в `~/.local/share/omarchy-ocr` и `~/.local/bin`.
6. Запрашивает горячую клавишу и записывает её в конфиг Hyprland.
7. Включает необходимые systemd-юниты.

Первый запуск занимает несколько минут: загружаются пакеты и модели.

### Неинтерактивная установка

```bash
./install.sh --hotkey "SUPER + ALT + PRINT" --obsidian
./install.sh --schedule "09:00-18:00" --days "1-5"
./install.sh --always-on --skip-deps --skip-models
```

| Опция | Значение |
|---|---|
| `--hotkey "..."` | горячая клавиша без интерактивного выбора |
| `--obsidian` | демон работает только при открытом Obsidian |
| `--schedule "09:00-18:00"` | демон работает по расписанию |
| `--days "1-5"` | дни недели для расписания (`1` = Пн … `7` = Вс) |
| `--always-on` | демон в автозапуске, завершение после часа простоя |
| `--skip-deps` | не изменять системные пакеты |
| `--skip-models` | не загружать модели повторно |
| `-y`, `--yes` | значения по умолчанию без вопросов |

### Выбор горячей клавиши

По умолчанию предлагаются варианты:

- `SUPER + ALT + SHIFT + PRINT`
- `SUPER + ALT + PRINT`
- `SUPER + SHIFT + PRINT`
- пользовательская комбинация

Горячая клавиша записывается в `~/.config/hypr/bindings.lua` (Omarchy 4) или `~/.config/hypr/hyprland.conf` (классический Hyprland) в блок с маркерами `>>> omarchy-ocr >>>`. Перед изменением создаётся резервная копия конфига. Для смены комбинации достаточно повторно запустить установщик.

## Использование

1. Нажмите горячую клавишу.
2. Выделите область с текстом или формулами.
3. Дождитесь уведомления «Текст и формулы в буфере».
4. Вставьте содержимое в нужное место.

Если выбран режим «только при Obsidian» и приложение закрыто, либо выбран режим расписания и текущее время вне окна, демон не запускается: срабатывает резервный one-shot режим (~15–20 с), при этом в памяти ничего не остаётся.

## Архитектура

```
hyprpicker + slurp + grim
        │  PNG
        ▼
omarchy-capture-formula ──socat──▶ omarchy-ocr.service (демон)
                                    ├─ MFD (Pix2Text) → где формулы
                                    ├─ MFR (Pix2Text) → LaTeX формул
                                    └─ EasyOCR        → текст (ru + en)
        ◀──────── OK + Markdown ────┘
        │
        ▼
     wl-copy + уведомления
```

Демон прослушивает Unix-сокет `$XDG_RUNTIME_DIR/omarchy-ocr.sock`. Модели загружаются однократно при старте демона, а не при каждом нажатии.

### Жизненный цикл

| Режим | Поведение |
|---|---|
| **Obsidian** (по умолчанию, если Obsidian установлен) | `omarchy-ocr-obsidian.service` отслеживает события Hyprland: при открытии окна Obsidian демон запускается, при закрытии последнего окна — останавливается. |
| **Расписание** | Демон запущен только внутри заданного временного окна и в выбранные дни. Obsidian при этом не учитывается. |
| **Всегда** | Демон в автозапуске, завершается после часа без запросов. |

Watcher работает на событийном сокете Hyprland (`.socket2.sock`) и отслеживает несколько окон Obsidian по адресам. Дополнительно раз в 30 секунд выполняется проверка расписания, поэтому переходы могут запаздывать до 30 секунд. Класс окна определяется по подстроке `obsidian` (`md.obsidian.Obsidian`).

### Расписание

Формат окна — `HH:MM-HH:MM`, дни — номера ISO (`1` — понедельник, `7` — воскресенье). Поддерживаются диапазоны и списки: `1-5`, `1,3,5`, `6-7`.

```text
09:00-18:00   # будни, днём
22:00-06:00   # ночная смена, переход через полночь поддерживается
00:00-23:59   # почти весь день (для «совсем всегда» есть режим always)
```

Конец окна не включается: окно `09:00-18:00` работает до `17:59:59`. Если время начала больше времени конца, окно считается ночным. Для ночного окна день определяется по дате начала: `22:00-06:00` с днями `1-5` включает ночь с пятницы на субботу до `06:00`.

Настройки хранятся в файлах:

| Файл | Значение |
|---|---|
| `~/.config/omarchy-ocr/mode` | `obsidian`, `schedule` или `always` |
| `~/.config/omarchy-ocr/schedule` | окно `HH:MM-HH:MM`; пусто — без ограничения |
| `~/.config/omarchy-ocr/days` | `1-7`, `1-5`, `1,3,5`; пусто — все дни |

Переключение режима вручную:

```bash
echo schedule > ~/.config/omarchy-ocr/mode
echo "09:00-18:00" > ~/.config/omarchy-ocr/schedule
echo "1-5" > ~/.config/omarchy-ocr/days
systemctl --user restart omarchy-ocr-obsidian.service  # применить сразу
```

Watcher перечитывает файлы раз в 30 секунд; перезапуск нужен только для немедленного применения.

Возврат к режиму Obsidian:

```bash
echo obsidian > ~/.config/omarchy-ocr/mode
: > ~/.config/omarchy-ocr/schedule
: > ~/.config/omarchy-ocr/days
systemctl --user restart omarchy-ocr-obsidian.service
```

В режиме `obsidian` пустой `schedule` означает «без ограничения по времени». Если заполнить `schedule` и `days`, демон будет работать только когда Obsidian открыт **и** время попадает в окно. Это позволяет не удерживать 1.4 ГБ RAM за пределами рабочих часов.

Наиболее простой способ задать расписание — через установщик:

```bash
./install.sh --schedule "09:00-18:00" --days "1-5"
```

Повторная установка в режимах `obsidian` или `always` очищает файлы `schedule` и `days`. Для комбинации «Obsidian + рабочие часы» необходимо установить режим `obsidian`, а затем заполнить эти файлы вручную.

## Производительность

| Случай | Время |
|---|---|
| Только текст | ~0.7–0.9 с |
| Формулы в строке | ~2.3 с |
| Текст + 2 формулы | ~2.9 с |
| Полный цикл с выделением и буфером | ~3–5 с |
| Холодный старт демона | ~11 с, в фоне |

Для сравнения: one-shot режим без демона — 15–20 с на каждый вызов.

## Настройки

Режим и расписание считываются watcher и скриптом захвата. Значения задаются через файлы (см. выше) или переменные окружения — последние удобны для проверки и имеют приоритет над файлами:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `OMARCHY_OCR_MODE` | из файла `mode` (`obsidian`) | `obsidian`, `schedule`, `always` |
| `OMARCHY_OCR_SCHEDULE` | из файла `schedule` (пусто) | окно `HH:MM-HH:MM` |
| `OMARCHY_OCR_SCHEDULE_DAYS` | из файла `days` (`1-7`) | дни недели |

Переменные окружения юнита `~/.config/systemd/user/omarchy-ocr.service`:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `OMARCHY_OCR_LANGS` | `ru,en` | языки EasyOCR; принимает `ru,en` и `eng+rus` |
| `OMARCHY_OCR_IDLE` | `0` / `3600` | простой до завершения, секунды (`0` — никогда) |
| `OMARCHY_OCR_RESIZED_SHAPE` | `768` | ширина, до которой масштабируется изображение |
| `OMARCHY_OCR_MFD_CONF` | `0.5` | порог детектора формул |

Порог `0.5` принципиален: при значении по умолчанию `0.25` детектор принимает точки над «ё» за математические акценты и искажает русский текст. Реальные формулы дают уверенность ~0.7–0.9.

Watcher можно перенастроить на другое приложение:

```bash
systemctl --user edit omarchy-ocr-obsidian.service
# [Service]
# Environment=OMARCHY_OCR_WATCH_PATTERN=zathura
```

Переменная `OMARCHY_OCR_SERVICE` позволяет управлять другим юнитом (по умолчанию `omarchy-ocr.service`).

После изменения юнита:

```bash
systemctl --user daemon-reload
systemctl --user restart omarchy-ocr-obsidian.service
```

## Управление

```bash
systemctl --user status omarchy-ocr-obsidian.service   # watcher
systemctl --user status omarchy-ocr.service            # демон
journalctl --user -u omarchy-ocr.service -f            # логи
```

## Диагностика

**Горячая клавиша не срабатывает.** Проверьте конфиг Hyprland:

```bash
hyprctl configerrors
```

Убедитесь, что блок `>>> omarchy-ocr >>>` присутствует в `~/.config/hypr/bindings.lua` или `~/.config/hypr/hyprland.conf`.

**Демон не запускается по расписанию.** Проверьте режим, окно и дни, затем перезапустите watcher или подождите до 30 секунд:

```bash
cat ~/.config/omarchy-ocr/mode
cat ~/.config/omarchy-ocr/schedule
cat ~/.config/omarchy-ocr/days
date +'%H:%M, день %u'
systemctl --user restart omarchy-ocr-obsidian.service  # или подождать до 30 с
journalctl --user -u omarchy-ocr-obsidian.service -n 30
```

Проверка расписания выполняется раз в 30 секунд, конец окна не включается. При опечатке в `schedule` watcher записывает предупреждение в лог и работает без ограничения по времени.

**Демон не отвечает.** Проверьте логи и сокет:

```bash
journalctl --user -u omarchy-ocr.service -n 50
printf '%s\n' /путь/картинка.png | socat - UNIX-CONNECT:"$XDG_RUNTIME_DIR/omarchy-ocr.sock"
```

**Ошибка `cannot import name 'resolve_model_key'`.** `cnstd` (зависимость Pix2Text) несовместима с `rapidocr >= 3.10`. Версия закреплена установщиком:

```bash
uv pip install --python ~/.local/share/pix2text-venv/bin/python 'rapidocr==3.9.2'
```

**Модели не загрузились.** Удалите `~/.pix2text` и `~/.EasyOCR`, затем выполните:

```bash
./install.sh --skip-deps
```

**Низкое качество распознавания.** Выделяйте область плотно по тексту, без больших полей и размытия. Для мелкого текста рекомендуется увеличить масштаб страницы.

**Отсутствуют уведомления.** Требуется `omarchy-notification-send` (Omarchy) или `notify-send` (`libnotify`). На Omarchy присутствует по умолчанию.

## Обновление

```bash
cd omarchy-ocr
git pull
./install.sh --skip-deps --skip-models
```

Установщик перезаписывает скрипты и юниты, повторно запрашивает режим, расписание и горячую клавишу, а также создаёт резервную копию конфига Hyprland.

## Удаление

```bash
./uninstall.sh           # сервисы, скрипты, горячая клавиша
./uninstall.sh --purge   # дополнительно venv и модели (~2.5 ГБ)
```
